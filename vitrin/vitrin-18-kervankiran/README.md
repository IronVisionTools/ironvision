# astro-kamp — KERVANKIRAN (örnek site)

VYRON site fabrikasının üretim örneği. Gerçek bir işletme değildir; marka, bungalovlar
ve fiyatlar kurgudur. Gökyüzü hesapları, fotoğraflar ve ölçümler gerçektir.

- Canlı: https://ironvisiontools.com/vitrin/vitrin-18-kervankiran/
- Yapım notu: https://ironvisiontools.com/vitrin/vitrin-18-kervankiran/rehber/
- Fotoğraf telifi: `gorseller-kaynak.md` (Pexels License)
- Üretim kaynağı: site-fabrikasi deposu, `hatlar/astro-kamp/`

Statik HTML/CSS/JS. Framework yok, derleme adımı yok. Gece çizelgesi hesabı
`js/gokyuzu.js` içinde, dış kütüphane kullanmıyor.
