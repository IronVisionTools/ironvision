Web siteleriOur websites

  • ironvisiontools.com ve moymote.com yalnızca HTTPS ile açılır; HTTP istekleri HTTPS'e yönlendirilir (13.10.2026 dış kontrol).
  • Yaygın gizli yollar (.env, .git, admin, yedek dosyaları) iki sitede de 404 döner; dizin listeleme yoktur.
  • Sahipsiz (askıda) alt alan adı bulunmadı.
  • moymote.com HSTS, X-Frame-Options: DENY, X-Content-Type-Options: nosniff ve Referrer-Policy başlıklarını gönderir. ironvisiontools.com GitHub Pages üzerinde çalışır ve bu ek başlıkları göndermez; bunu bildiğimiz için burada iddia etmiyoruz.
  • ironvisiontools.com and moymote.com are served over HTTPS only; HTTP requests are redirected to HTTPS (external check, 13 Oct 2026).
  • Common hidden paths (.env, .git, admin, backup files) return 404 on both sites; directory listing is off.
  • No dangling (orphaned) subdomains were found.
  • moymote.com sends HSTS, X-Frame-Options: DENY, X-Content-Type-Options: nosniff and Referrer-Policy headers. ironvisiontools.com runs on GitHub Pages and does not send these extra headers; we say so rather than claim otherwise.

Kod ve sırlarCode and secrets

  • 38 kod deposunun tüm git geçmişi gitleaks 8.30.1 ile tarandı (13.10.2026): geçerli bir sır (anahtar, token, parola) bulunmadı; çıkan 4 eşleşmenin hepsi yanlış pozitifti.

  • No internal addresses or local paths were found in our public repositories.

AltyapıInfrastructure

  • Sunucumuza SSH yalnızca anahtarla girilir; parola ile giriş kapalıdır ve internetten SSH erişimi yoktur.
  • Bulut depolama kovalarımızda herkese açık erişim engelli ve şifreleme açıktır; kök hesapta çok adımlı doğrulama açıktır ve kök erişim anahtarı yoktur.
  • SSH to our server is key-only; password login is disabled and SSH is not reachable from the internet.
  • Our cloud storage buckets block public access and are encrypted; the root account has multi-factor authentication on and has no root access key.

MoyMote (Windows uygulaması)MoyMote (Windows app)

  • Kod incelemesiyle (13.09.2026) doğrulandı: uygulama analitik toplamaz, güncelleme kontrolü yapmaz, dış sunuculara istek atmaz.
  • Telefon için açtığı yerel sunucu tüm ağ arayüzlerine birden değil, yalnızca belirli yerel ağ (ve varsa Tailscale) adreslerine bağlanır; güvenlik duvarı kuralı yalnızca özel ağ profilinde TCP 8765'i açar.
  • Bağlantı anahtarı bilgisayarında rastgele üretilir ve orada saklanır; bize gönderilmez. Tek kullanımlık değildir: dosyayı silip uygulamayı yeniden başlatarak yenilenir.
  • Teknik günlük dosyası yalnızca bilgisayarında durur ve 2 MB'ı geçince döndürülür.
  • Bilinen sınır: yerel ağdaki telefon bağlantısı şifrelenmemiş HTTP kullanır. Bu yüzden yalnızca güvendiğin bir ağda kullan. Şifrelemeyi henüz eklemedik.
  • Verified by code review (13 Sep 2026): the app collects no analytics, does no update check and makes no requests to external servers.
  • The local server it opens for your phone does not bind to all network interfaces at once, only to specific local-network (and, if installed, Tailscale) addresses; the firewall rule opens TCP 8765 on the private network profile only.
  • The connection key is generated randomly on your computer and stored there; it is never sent to us. It is not single-use: delete the file and restart the app to renew it.
  • The technical log file stays on your computer and rolls over at 2 MB.
  • Known limit: the phone connection on your local network uses unencrypted HTTP, so use it only on a network you trust. We have not added encryption yet.
